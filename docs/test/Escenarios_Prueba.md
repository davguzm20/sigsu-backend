# Escenarios de prueba

| ID | Área | Escenario |
|---|---|---|
| ESC-01 | Acceso | Un usuario inicia sesión con sus credenciales, consulta su perfil y cierra sesión. |
| ESC-02 | Registro y consulta | Un solicitante registra una solicitud, adjunta evidencia, la consulta y la comenta. |
| ESC-03 | Clasificación | Un supervisor clasifica la solicitud con categoría, prioridad y área, y consulta las pendientes de asignar. |
| ESC-04 | Asignación | Un supervisor asigna un técnico y el técnico consulta lo que tiene asignado. |
| ESC-05 | Atención y seguimiento | Un técnico inicia la atención, actualiza el estado, comenta, adjunta evidencia y consulta el historial. |
| ESC-06 | Resolución y cierre | Un técnico registra la solución y marca resuelta; el supervisor revisa y cierra. |
| ESC-07 | Dashboard | Un supervisor consulta los indicadores y los filtra por fecha, categoría y prioridad. |
| ESC-08 | Administración | Un administrador gestiona usuarios, roles, categorías, prioridades, estados y áreas. |
| ESC-09 | Vigencia | El sistema muestra cuánto tiempo puede estar una solicitud en cada estado y el tiempo estimado de solución. |
| ESC-10 | Duplicados | Al revisar una solicitud, el supervisor ve las demás solicitudes del mismo solicitante. |
| ESC-11 | Calificación | El solicitante califica la calidad del servicio después de que la solicitud se resuelve o se cierra. |
